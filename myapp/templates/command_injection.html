Command Injection

Command Injection이란?
웹 애플리케이션에서 사용자 입력값을 검증하지 않고 운영체제 명령어로 실행할 때, 공격자가 임의의 시스템 명령어를 삽입하여 실행하는 공격 기법입니다. 시스템 파일 접근, 권한 탈취, 원격 제어 등이 가능합니다.

공격 예제

정상 입력: date → 현재 날짜/시간 출력

악의적 입력 (Linux):

# 명령어 체이닝을 이용한 공격
date; cat /etc/passwd
date && whoami
date | ls -la

# 파일 조회
cat /etc/passwd

# 시스템 정보 탈취
uname -a

# 네트워크 정보
ifconfig

악의적 입력 (Windows):

# 명령어 체이닝
dir & whoami
dir && type C:\Windows\System32\drivers\etc\hosts

# 시스템 정보
systeminfo

💡 취약한 코드 vs 안전한 코드

# ❌ 취약한 코드
import os
result = os.popen(user_input).read() # 위험!
# 사용자 입력이 직접 시스템 명령어로 실행됨

# ✅ 안전한 코드 (화이트리스트 방식)
allowed_commands = {
  'date': ['date'],
  'hostname': ['hostname'],
}
if user_input in allowed_commands:
  subprocess.run(allowed_commands[user_input], shell=False)

특수문자를 이용한 명령어 체이닝

  • ; (세미콜론) - 첫 번째 명령 실행 후 두 번째 명령 실행
  • && (AND) - 첫 번째 명령 성공 시 두 번째 명령 실행
  • || (OR) - 첫 번째 명령 실패 시 두 번째 명령 실행
  • | (파이프) - 첫 번째 명령 출력을 두 번째 명령 입력으로
  • & (백그라운드) - 명령을 백그라운드에서 실행
