Code Injection

Code Injection이란?
애플리케이션에서 외부 입력값을 검증하지 않고 프로그래밍 언어의 코드로 실행할 때, 공격자가 임의의 코드를 삽입하여 실행하는 공격 기법입니다.
{% csrf_token %}

공격 예제

정상 입력: 2 + 3 → 결과: 5

악의적 입력: __import__('os').system('whoami')

# eval() 함수는 문자열을 Python 코드로 실행
# 공격자는 os.system() 등을 삽입하여 시스템 명령어 실행 가능
result = eval(user_input) # 위험!

더 위험한 예제

  • __import__('os').system('ls -la') - 파일 목록 조회
  • open('/etc/passwd').read() - 시스템 파일 읽기
  • __import__('subprocess').getoutput('whoami') - 명령 실행

💡 취약한 코드 vs 안전한 코드

# ❌ 취약한 코드
result = eval(user_input) # 모든 Python 코드 실행 가능

# ✅ 안전한 코드
# 1. 입력값 검증 (숫자와 연산자만 허용)
if all(c in '0123456789+-*/(). ' for c in user_input):
  result = eval(user_input, {"__builtins__": {}}, {})

# 2. eval() 대신 ast.literal_eval() 사용
import ast
result = ast.literal_eval(user_input) # 리터럴만 허용
